RaidMaster-Uploader – schickt die RaidMaster-Daten vom PC der Raidleitung an den Discord-Bot
==========================================================================================

1. Python 3 installieren (kostenlos auf python.org, bei der Installation "Add Python to PATH" anhaken).
2. Diesen Ordner "RaidMasterUploader" z. B. nach Dokumente legen.
3. Im Discord /uploader eingeben (nur Admins). Die Datei uploader_config.json, die der Bot schickt,
   in diesen Ordner legen. NIE weitergeben – sie enthält einen geheimen Link zu eurem Discord.
4. uploader.bat doppelklicken und das Fenster offen lassen.
5. Automatisch mit Windows starten: Windows-Taste + R, shell:startup eingeben, eine Verknüpfung zu
   uploader.bat hineinlegen.

Nach jedem /reload oder Ausloggen sind DKP, Loot, Einteilung und Skillungen nach wenigen Sekunden im
Discord.

Ab Version 1.6.0: Beim Erstkill eines Bosses macht RaidMaster einen Screenshot. Der Uploader sucht ihn im
Screenshots-Ordner von WoW und schickt ihn mit dem nächsten Upload mit – in #ruhmeshalle erscheint er dann
mit allen Teilnehmern. Andere Screenshots werden nie hochgeladen. Liegt der Ordner woanders: in
uploader_config.json "screenshots_path" eintragen. Im Spiel zeigt die Seite "Discord" (oder /rm discord) die ganze Anleitung.

- Den alten Ordner "RaidMasterUploader" durch den neuen ERSETZEN – nicht in den alten Ordner hineinentpacken.

- Beim Start zeigt das Fenster die Version (z. B. "RaidMaster-Uploader 1.7.0").

  DATEN FÜR DIE PRÜFUNG (nur für den Entwickler des Addons nötig, sonst einfach weglassen)
  Der Uploader legt nach jedem /reload und Ausloggen die Daten der GoldSentinel-Addons (AHSentinel, GuildSentinel,
  ProfessionSentinel, LevelPilot, ThreatSentinel, BuffSentinel, RaidMaster – nur Kontoebene, keine anderen Addons) in
  ein PRIVATES GitHub-Repo. Dort liegt immer nur der neueste Stand und der letzte Stand der letzten 7 Spieltage;
  ältere Fassungen werden gelöscht (kein Verlauf). Ist das Repo nicht privat, liefert der Uploader nichts.
  Einmal einrichten:
  1. github.com -> oben rechts "+" -> "New repository". Name: goldsentinel-daten. "Private" wählen. "Create
     repository". (Nichts weiter ausfüllen.)
  2. Token: oben rechts auf dein Bild -> Settings -> ganz unten links "Developer settings" -> "Personal access
     tokens" -> "Fine-grained tokens" -> "Generate new token".
     - Token name: GoldSentinel-Daten. Expiration: z. B. 1 Jahr.
     - Repository access: "Only select repositories" -> goldsentinel-daten auswählen.
     - Permissions -> Repository permissions -> "Contents": "Read and write" (Metadata: Read-only kommt von selbst).
     - "Generate token" und den Token kopieren (er wird nur einmal angezeigt).
  3. Im Uploader-Ordner Daten-Repo-einrichten.bat doppelklicken, Repo eingeben (z. B. deinname/goldsentinel-daten),
     Token einfügen (Rechtsklick fügt ein; er wird nicht angezeigt), Enter. Der Uploader prüft, ob das Repo privat
     und erreichbar ist, und speichert beides in daten_config.json (geheim, nie weitergeben).
  4. Uploader neu starten. Im Fenster steht dann "Prüfung: zuletzt geliefert 19:36 (3 Dateien) · Repo 12,3 MB".
  Den Token nie in Discord oder einen Chat kopieren. Läuft er ab: neuen Token anlegen, Schritt 3 wiederholen.
