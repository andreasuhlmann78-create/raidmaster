## AHSentinel 0.65.409

**Deutsch**
- **Wächter flüssiger:** bei vielen Angeboten (z. B. 4 500) holte der Wächter bei jeder neuen Ergebnisseite die ganze Liste vom Spiel neu (je etwa 9 ms und 3,7 MB). Jetzt hängt er nur die neuen Einträge an, die das Spiel mit der Seite mitschickt – die ganze Liste wird einmal je Runde gelesen.

**English**
- **Watcher smoother:** with many offers (e.g. 4 500), each new result page made the watcher fetch the whole list from the game again (about 9 ms and 3.7 MB each time). It now adds only the new entries the game sends with the page – the whole list is read once per round.
