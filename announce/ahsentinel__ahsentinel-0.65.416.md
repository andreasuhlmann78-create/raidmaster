## AHSentinel 0.65.416

**Deutsch**
- **Schnellere Preis-Abfragen anderer Addons (z. B. ProfessionSentinel):** die erste "Lohnt bis"-Abfrage einer Sitzung konnte 18–21 ms dauern, weil AHSentinel einen Index über die ganze Buchhaltung neu baute. Neue Buchungen werden jetzt nur angehängt, der Index wird nach dem Einloggen im Hintergrund gebaut, und der Absatz je Tag wird aus den Einträgen des Items gezählt. Gleiche Werte wie bisher.

**English**
- **Faster price questions from other addons (e.g. ProfessionSentinel):** the first "worth up to" query of a session could take 18–21 ms because AHSentinel rebuilt an index over the whole ledger. New bookings are now only appended, the index is built in the background after logging in, and sales per day are counted from the item's own entries. Same values as before.
