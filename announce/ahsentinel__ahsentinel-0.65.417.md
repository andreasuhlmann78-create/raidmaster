## AHSentinel 0.65.417

**Deutsch**
- **Weniger Chat, nur was dir hilft:** beim Einloggen nur noch eine Zeile mit Version ("AHSentinel 0.65.417 – /ahs oder der Münz-Button öffnet das Fenster"). Die Tagesbilanz kommt nur, wenn es etwas zu melden gibt.
- **Fehler:** im Chat nur noch eine kurze Zeile je Sitzung ("Ein Fehler ist aufgetreten – er wird automatisch gemeldet"); die Einzelheiten gehen wie bisher in die Fehlerliste.
- **Tipps nur einmal:** Hinweise wie der Raid-Start-Hinweis erscheinen ein einziges Mal und danach nie wieder.
- **Optionen in verständlichen Worten:** das Vollscan-Tempo zeigt "sehr flüssig / flüssig / ausgewogen / schneller" statt Millisekunden; "Preis-Sync" heisst jetzt "Preise teilen".
- Im Testmodus bleibt alles wie bisher sichtbar.

**English**
- **Less chat, only what helps you:** on login just one line with the version ("AHSentinel 0.65.417 – /ahs or the coin button opens the window"). The daily summary only appears when there is something to report.
- **Errors:** in chat only one short line per session ("An error occurred – it is reported automatically"); the details still go to the error list.
- **Tips only once:** hints such as the raid start notice are shown a single time and then never again.
- **Options in plain words:** the full scan speed shows "very smooth / smooth / balanced / faster" instead of milliseconds; "price sync" is now called "share prices".
- In test mode everything stays visible as before.
