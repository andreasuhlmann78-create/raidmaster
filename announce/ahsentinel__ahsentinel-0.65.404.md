## AHSentinel 0.65.404

**Deutsch**
- **Flüssiger nach einem Scan:** die eingebaute Liste der Item-Namen wird mit einem kleineren Zeitanteil je Bild aufgebaut (höchstens ~6 ms statt bis ~8 ms eigene Arbeit je Bild).

**English**
- **Smoother after a scan:** the built-in item name list is now built with a smaller time slice per frame (at most ~6 ms instead of up to ~8 ms of own work per frame).
