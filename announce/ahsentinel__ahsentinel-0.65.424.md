## AHSentinel 0.65.424

**Deutsch**
- **Diagnose:** auf WoW Forever meldet der Server den eigenen Sniper-Kauf zusätzlich als "Auktion abgebrochen" mit derselben Auktion. Das Protokoll nennt das jetzt "eigener Kauf" statt "unerwartet". Gebucht oder geändert wird nichts.

**English**
- **Diagnostics:** on WoW Forever the server also reports your own sniper purchase as "auction cancelled" with the same auction. The log now names this "own purchase" instead of "unexpected". Nothing is booked or changed.
