## AHSentinel 0.65.418

**Deutsch**
- **Diagnose für Preis-Abfragen anderer Addons:** dauert eine "Lohnt bis"-Abfrage (z. B. von ProfessionSentinel) 4 ms oder länger, schreibt das Diagnose-Protokoll, wie lange jeder Teil gedauert und wie viel Speicher er gebraucht hat (höchstens 20 Zeilen je Sitzung). Keine Änderung an Werten oder Anzeigen.

**English**
- **Diagnostics for other addons' price questions:** if a "worth up to" question (e.g. from ProfessionSentinel) takes 4 ms or more, the diagnostic log notes how long each part took and how much memory it used (at most 20 lines per session). No change to any value or display.
