## AHSentinel 0.65.388

**Deutsch**
- **Vollscan-Messung (nur Testroutine):** der Bericht zum längsten Bild nennt alle Gesamtwerte des Speichers (Scan-Beginn, im Bild, vor und nach der Messung je Addon) und ob während dieser Messung eine Speicherbereinigung lief. Die Werte je Addon heissen jetzt "belegter Speicher".
- **Bilder pro Sekunde:** als Mittelwert des Spiels beschriftet, daneben das längste Bild je Schritt.
- **Neue Messung im längsten Bild beim Einlesen (nur Testroutine):** Spiel-Ereignisse in diesem Bild (nur Namen und Anzahl), Auktionshaus-Fenster offen?, gelesene Auktion; Kosten der Messung stehen dabei.
- **Gemeinsame Testdatei Version 3:** eine Prüfung ohne Ergebnis zählt als FEHLER.
- **Versionshinweise auf GitHub:** zuerst Deutsch, Englisch zusätzlich.

**English**
- **Full scan measurement (test routine only):** the report on the longest frame shows all total memory values and whether a garbage collection ran during the per-addon measurement; per-addon values are labelled as memory in use.
- **Frames per second:** labelled as the game's average, with the longest frame of each step next to it.
- **New measurement in the longest frame while reading (test routine only):** game events in that frame (names and counts only), Auction House window open?, auction being read; the cost of the measurement is shown.
- **Shared test file version 3:** a check that returns nothing counts as an error.
- **Release notes:** German first, English in addition.
